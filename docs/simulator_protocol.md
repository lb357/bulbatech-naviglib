# Протокол симулятора

Связь с симулятором (сервером) осуществляется через протокол WebSocket массивами байт (bytes, PoolByteArray, Array[byte], PacketByteArray, etc)

## Типы данных
| Тип | Диапазон | Количество занимаемых байт |
| - | - | - |
| byte | 0...255 | 1 |
| int | -2^63...2^63 | 8 |
| double |  1.7e-308...1.7e+308| 8 |

## Структура
|  Описание запроса | Запрос | Ответ | Описание данных |
| - | - | - | - |
| Начальный "Пинг" (получение данных о виртуальной камере)| `0: byte `, `vp_id: int`| `0: byte`, `vp_id: int`, `h: int`, `w: int`, `f: int`| `vp_id` - id камеры в симуляторе<br>`w`/`h` - размеры изображения в пикселях<br>`f` - формат изображения [(см. документацию Godot)](https://docs.godotengine.org/en/latest/classes/class_image.html#enum-image-format) |
| Плавное перемещение дрона к заданным координатам | `1: byte`, `x: double`, `y: double`, `z: double` | `1: byte` | `x`/`y`/`z` - координаты целевой позиции дрона |
| Плавный поворот дрона к заданному углу | `2: byte`, `rx: double`, `ry: double`, `rz: double` | `2: byte` | `rx`/`ry`/`rz` - целевой поворот дрона |
| Получение координат и поворота дрона | `3: byte` | `3: byte`, `x: double`, `y: double`, `z: double`, `rx: double`, `ry: double`, `rz: double` | `x`/`y`/`z` - координаты целевой позиции дрона,<br>`rx`/`ry`/`rz` - целевой поворот дрона |
| Получение изображения с виртуальной камеры | `4: byte `, `vp_id: int`| `4: byte`, `vp_id: int`, `img[0]: byte`, `img[1]: byte` ... `img[n]: byte` | `vp_id` - id камеры в симуляторе<br>`img` - массив байт данных о каждом пикселе изображения, сжатый алгоритмом gzip |
