# Overview
## BulbaTech-naviglib - система для нахождения координат агродрона по камерам на нём.
`/lib` - Python библиотека с решением (`btm.py` содержит основные файлы, `main.py` содержит типовой пример использования, работающий в рамках симуляции)<br>
`/sim` - Godot проект симулятора для тестирования библиотеки
